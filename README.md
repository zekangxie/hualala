# Hualala

把中文原稿改成可以直接录制的短视频口播。先盘点值得复用的素材，再由你选改稿方式。

## 使用

下载或克隆仓库，在 Codex 打开仓库目录。也可以把整个技能目录复制到自己项目的 .agents/skills/ 下。在 Codex 输入 `$hualala` 并贴稿。

> 用 $hualala 处理下面这篇稿。先盘点值得保留的素材，再让我选择改稿方式。

支持浅度洗稿、深度洗稿、选题复刻、长稿短改、信息深化和多稿合一。确认方式后，按七个维度改稿，用十个基于公开作品的审稿视角校核。交付口播终稿、5–10 个备选开头和流量简报。流量简报衡量稿件与受众的文本匹配。
